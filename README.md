📱 Projeto: Conversor de Unidades (Java)

🎯 Objetivo
Criar um aplicativo Android no Android Studio utilizando a linguagem Java, com a funcionalidade de converter unidades de medida entre centímetros, metros, quilômetros e milhas.

🧩 Funcionalidades Principais
- Permite ao usuário digitar um valor.
- O usuário escolhe a unidade de origem e a unidade de destino usando spinners.
- Ao clicar no botão "Converter", o app realiza a conversão com base na seleção e apresenta o resultado.

🛠️ Componentes da Interface
- EditText – Entrada do valor a ser convertido.
- Spinner (2x) – Para as seleções de unidade de entrada e de saída.
- Button – Dispara o processo de conversão.
- TextView – Mostra o valor convertido.

🔄 Unidades Suportadas
- Centímetros (cm)
- Metros (m)
- Quilômetros (km)
- Milhas (mi)

🧮 Exemplos de Conversão
- 1000 metros → 1 quilômetro
- 1 milha → 1609,34 metros
- 5000 centímetros → 50 metros

✅ Requisitos Técnicos
- Aplicativo com interface intuitiva e responsiva.
- Implementação da lógica usando estruturas condicionais (if-else).
- Código limpo, organizado e comentado.
- Funciona corretamente em diferentes tamanhos de dispositivos.
